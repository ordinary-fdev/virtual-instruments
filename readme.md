# 🎹 Virtual Instruments

A cinematic browser-based virtual instrument experience powered by real-time hand tracking, immersive audio, and premium UI effects.

Built with:
- HTML/CSS/JavaScript
- Tone.js

---

# ✨ Features

## 🎼 Multiple Instruments
Switch between:
- Grand Piano
- Flute
- Guitar
- Bass Guitar
- Harmonium
- Violin
- Saxophone
- Organ
- Xylophone
- Bells
- Synth

---

# 🎹 Piano Experience

Designed to feel cinematic and premium:
- Glassmorphism UI
- Dynamic glow effects
- Piano reflections & shadows
- Responsive key animations
- Sustain pedal support using `SPACE`

---

# 🔊 Audio Engine

Powered by Tone.js for:
- Low latency playback
- High quality synthesis
- Instrument switching
- Real-time note triggering

---

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/your-username/virtual-instruments.git
cd virtual-instruments
````

---

## 2. Run Locally

Because MediaPipe and modules require a local server, use:

### VS Code Live Server

OR

### Python Server

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
